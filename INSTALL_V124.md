# Install V1.2.4 — Portrait Recovery Preview

**Recommended:** Extract the full project into a new directory. Copy your working `.env` from V1.2.3 and, if desired, back up and copy `save/world.json`. Do **not** copy the `.venv` virtual environment.

**Overlay:** From inside the original `The_Living_Counter_POC`, extract the overlay ZIP and allow overwrite; its paths are rooted directly at that folder. It excludes `.env`, `save/`, and `backend/exodia.py`.

Run `powershell -ExecutionPolicy Bypass -File .\start_windows.ps1`; then open `godot/project.godot`. Open F11 Gallery, choose **Master Chen Wei**, and press **F2** while the encounter is idle to cycle the **four unapproved** candidate portraits. A normal next dialogue action returns to normal production art. No missing states are synthesized, and no trade values change.

Run `powershell -ExecutionPolicy Bypass -File .\tools\preflight_v124_windows.ps1` to inspect local prerequisites.

**Caveat:** The 12-state art contract remains blocked for seven visitors. No Godot/Exodia/Hermes Windows runtime test has been performed here.
