# Hermes integration notes — V0.9.2

The game sends a fixed voice/profile per encounter and requests `speed=1.0`, `pitch_shift=0`. The Hermes server may still synthesize unusually slow or low-pitched speech because model prosody varies across generations; this cannot be fixed by trimming Exodia prompts. F5 now displays actual PCM seconds, played seconds, underruns and approximate glyphs per second of the last spoken segment. If the speech is slow without underruns and the actual request is 1.0x, investigate model voice preset, voice reference audio, and instruction compatibility on the Hermes server. If underruns are nonzero, inspect network buffering and generation-to-playback rate. Actual word timestamps remain a separate Hermes API enhancement and are not claimed here.
