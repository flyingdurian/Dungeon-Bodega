# V1.0.0 Visual Art & UI Bible

## Core visual standard
Rich illustrated fantasy/modern crossroads shop. Warm lantern lighting, painterly mahogany, blue-and-white porcelain, jade, cherry blossoms, purple-black dialogue surfaces with gold highlights. No flat vector character replacements, no fake screenshot UI overlays.

## Composition (design space 1440×900, scaled to 1280×800)
- Top-left restrained title plate; status ribbon across remainder of top edge.
- Left narrow native navigation; the main illustration and transparent actor are dominant.
- Right: data card with title, disposition, current item, listed price and customer offer; five functional negotiation choices below.
- Bottom center: one large rich-text dialogue plate, separate nameplate and replay; input directly beneath.
- Hidden overlays: visitor gallery F11, voice diagnostics F5, performance studio F8, memory F9 and ledger F10.

## Emotional type
- Gold: measured gold/value; light lift and warm shimmer.
- Red: anger/ultimatums; visible stagger/vibration and short accent flash.
- Cyan: persuasion/conditional offers; underline and flowing motion.
- Violet: doubt, hesitation; soft wavering.
- Rose: teasing and flirting; gentle bounce and accent hearts.
- Amber: delight; bright uplift.
- Cool blue: sadness; lower and slower motion.
- Green: secure agreements (game-authoritative only).
No more than four phrase emphasis cues per line; each is synchronized to the text reveal progress. The content of the NPC's answer is never altered by typography.

## Art production gates
1. One high-resolution fully transparent base portrait per character (not a cropped photo-card).
2. Five or more carefully matched expressions with identical framing/scale/eyes and hair silhouette; do not use separately drifted full poses as replacements.
3. Preview at gameplay size in Godot, compare against approved visual reference. Run acceptance on all facial states.
4. New visitors Elara, Rin, Master Chen currently have **illustrated bust preview assets**, so these are NOT final art-approved until independent originals replace them.
